# Фоновые видео

Положи сюда свои записи геймплея в формате mp4 (любое разрешение, лучше 1080p и выше).
Конвейер случайно выбирает файл и случайный фрагмент нужной длины, обрезает до 9:16.

Правила:
- только собственная запись или геймплей, разрешённый издателем игры;
- без музыки из игры и без чужого голоса, звук фона всё равно отключается;
- один файл на 10–20 минут даёт сотни уникальных фрагментов.
